Comment créer une alerte ?

body: >-

Créer une alerte

Pour créer une nouvelle alerte, cliquez sur l'onglet "Alertes", puis sur le bouton "Créer" en haut au-dessus de la liste des alertes.
Indiquer les informations de l'alerte créée

Il s'agit des informations à remplir lors de la création de l'alerte.

Titre  : Le titre de votre alerte.

Type d'alerte : Définit la couleur d'apparition de votre bandeau d'alerte. Il existe trois types d'alerte : Information (bleu) ; Alerte (jaune) ; Alerte rouge (rouge).

Description : Cet espace vous permet d'ajouter une description à votre alerte. Vous pouvez choisir de publier l'alerte directement en activant l'option "Publié".
Vous pourrez également publier l'alerte après sa création. Vous pouvez aussi décider de lier votre alerte à une URL via l'option : "Afficher un bouton d'action". Dans ce cas, l'utilisateur sera redirigé vers l'URL indiqué lorsqu'il cliquera sur le bandeau.

Alerte créée

Une fois vos alertes créées, elles sont organisées comme vous pouvez le voir sur la capture d'écran. La pastille verte indique que l'alerte est publiée.
Publier une alerte

Pour publier une alerte après sa création, cliquez sur l'alerte que vous souhaitez publier. L'onglet "publier" en haut à droite vous permet de publier l'alerte. 
Traduire une alerte

Vous pouvez traduire les alertes en cliquant sur la langue souhaitée puis en saisissant la traduction de l'alerte. Lorsque le contenu est traduit, la pastille à côté de la langue traduite devient verte. Si le contenu n'est pas traduit, la pastille reste grise.
