Comment activer les alertes ?

body: >-

Activer les alertes

Pour ajouter la fonctionnalité "Alertes", vous devez cliquer sur l'onglet "Réglages" présent sur toutes les pages.

Ensuite, cochez la case "Alertes" pour l'activer.
