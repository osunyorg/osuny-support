Comment ajouter des fichiers ?

body: >-

Ajouter un bloc

Rajoutez du contenu dans vos pages en cliquant sur le bouton "ajouter"

Choisir le bloc fichiers
Remplir le bloc

Vous pouvez nommer votre fichier, le décrire, puis sélectionner le fichier correspondant directement sur votre ordinateur ou depuis l'espace de gestion des fichiers

Cliquez sur "envoyer un fichier" pour envoyer un fichier directement depuis votre ordinateur.

Cliquez sur "choisir un fichier dans la bibliothèque" pour accéder à l'espace de gestion des fichiers et sélectionner votre fichier.
Exemples

Vous trouverez différents types d'exemples de mise en page de fichiers sur Example.osuny.org
