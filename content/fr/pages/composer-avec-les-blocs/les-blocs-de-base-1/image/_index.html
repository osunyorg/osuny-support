Comment ajouter une image ?

body: >-


Le bloc image va vous permettre de rajouter une image avec sa description alternative, son texte et son crédit.

Ajout d'un bloc

Sur la page ou l'actualité que vous avez créée, cliquez sur "ajouter un bloc" pour commencer à ajouter des blocs de contenu.

Ajout du bloc Image

Cliquez sur le bloc image pour l'ajouter.
Remplir les informations du bloc

Vous pouvez envoyer des images directement depuis votre appareil, les importer depuis Unsplash ou Pexels ou bien les choisir dans la photothèque.

En cliquant sur photothèque, vous accédez au panneau de sélection d'images depuis la photothèque. Vous pouvez filtrer vos recherche via le panneau à gauche.

Vous avez accès à des banques d'images en libre accès via Unsplash ou Pexels

Vous pouvez ajouter des images directement depuis les dossiers de votre appareil.

Une fois votre photo importez, remplissez sa légende ainsi que son texte alternatif si besoin. Pour plus d'informations sur les mesures d'accessibilité, et la nécessité d'inclure un texte alternatif, rendez-vous sur cette page .

Une fois le bloc image créé, vous pouvez le positionner dans votre page.
